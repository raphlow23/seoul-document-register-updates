서울센터 공문 업무 v2.10.2 업데이트 복구

1. 실행 중인 서울센터 공문 프로그램을 종료합니다.
2. 이 ZIP을 모두 압축 해제합니다.
3. repair-update.cmd를 더블클릭합니다.
4. '복구 완료: v2.10.2'이 나오면 프로그램이 다시 열립니다.
5. 프로그램 상단에서 v2.10.2을 확인합니다. 예전 공유폴더 자료 이전은 실행할 때 자동 진행하지 않습니다.
6. 수신 없이 새 공문을 보내려면 '발신 작성 → ＋ 새 발신 작성'을 선택하세요.
7. 문제가 났던 메일 ZIP은 목록에서 삭제한 뒤 다시 추가하세요. 내부 PDF를 우선 읽으며, 다른 첨부파일로 바꾸거나 제목을 직접 입력할 수 있습니다.
8. 제목 확인 화면의 '본문 크게'로 OCR 본문을 넓게 읽고 선택 문장을 제목으로 넣을 수 있습니다.
9. 발신 정보에서 '대장 등록 → 번호로 HWP 저장'을 누르면 실제 발신번호 확인 후 번호.당일날짜. 제목.hwp로 저장합니다.
10. 직인대장 서식 오류로 멈춘 공문은 같은 공문에서 다시 등록하세요. 기존 값이 일치하면 같은 행의 서식을 맞춰 재확인합니다. 시트 탭은 이전·다음 시트 단축키로 선택합니다.
11. 한글의 정상 파일 접근 확인창은 '접근 허용'을 눌러 진행합니다. HWP 저장은 문서를 닫고 잠금 해제 확인 후 검증·복사합니다. 발신번호를 다시 받지 않고 같은 공문에서 저장을 재시도할 수 있습니다.
12. 발신 정보에서 'HWP 문서만 저장' 또는 '공문폴더를 만들어 저장'을 선택하세요. 양식 관리의 '기본 발신 제목' 또는 발신 화면의 '현재 제목을 이 양식 기본 제목으로 저장'으로 다음 새 발신의 시작 제목을 설정할 수 있습니다.

13. 설정 · 연결 → 대장별 구글 시트 연결에서 공문·업무연락·처리지침의 수신·발신·직인대장별 주소와 하단 탭을 저장합니다. 각 문서의 연결 확인 · 변경 버튼으로 해당 문서만 다르게 지정할 수 있습니다. 등록을 시작한 문서는 당시 연결을 유지합니다.
14. 이전 단계 (등록·파일 취소)는 프로그램이 등록한 내용과 생성 파일·폴더를 함께 취소합니다. 구글 시트 행 자체, 번호 기준과 서식은 유지합니다. 다른 사람이 수정한 행이나 파일이 있으면 중단합니다. 다시 등록할 때 시트의 최신 번호를 확인합니다.
15. 한글 저장 중 이전 단계를 누르면 작업 종료 후 취소합니다. 한글 열기는 다운로드 확인 작업이 끝나면 자동으로 이어서 실행합니다.

16. HWP 서식 비교 오류가 났던 공문은 같은 문서의 등록 완료 화면에서 HWP 저장하고 한글 열기를 다시 누르세요. 기존 발신·직인 등록과 번호를 유지한 채 저장만 재시도합니다. 원본을 현재 한글에서 무수정 저장한 기준본과 비교하며, 검증 실패 시 설치 폴더의 임시보관/HWP-서식확인에 확인 자료를 남깁니다.

17. 발신 양식 선택 화면에서 양식 수정 또는 양식 삭제를 누릅니다. 양식 수정 → 한글에서 양식 수정 → Ctrl+S로 저장하고 한글 닫기 → 수정본 다시 읽기 → 수정 내용 저장 순서로 적용합니다. 원본은 적용 전까지 유지합니다. 양식 삭제는 선택 목록에서만 제거하며 기존 공문용 양식은 보관합니다.

기존 프로그램 삭제는 필요 없습니다. 설정·접수 이력·개인 HWP 양식은 유지합니다.
GitHub 공식 배포 API에서 수정본을 내려받고, 고정된 SHA-256 해시와 기존 프로그램의 전자서명 검사로 확인한 뒤 교체합니다.
성공한 복구 임시자료는 설치 프로그램 폴더 안에서 정리합니다. 기존 실행 파일은 .previous로 보관합니다.
기존 프로그램을 설치했던 Windows 계정에서 실행해 주세요.
