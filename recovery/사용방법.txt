서울센터 공문 업무 v2.8.3 업데이트 복구

1. 실행 중인 서울센터 공문 프로그램을 종료합니다.
2. 이 ZIP을 모두 압축 해제합니다.
3. repair-update.cmd를 더블클릭합니다.
4. '복구 완료: v2.8.3'이 나오면 프로그램이 다시 열립니다.
5. 프로그램 상단 버전을 확인합니다. 멈춘 공유폴더 정리는 설정의 '이전 공유폴더 · 임시자료 정리'에서 다시 실행할 수 있습니다.

기존 프로그램 삭제는 필요 없습니다. 설정·접수 이력·개인 HWP 양식은 유지합니다.
GitHub 공식 배포 API에서 수정본을 내려받고, 고정된 SHA-256 해시와 기존 프로그램의 전자서명 검사로 확인한 뒤 교체합니다.
성공한 복구 임시자료는 설치 프로그램 폴더 안에서 정리합니다. 기존 실행 파일은 .previous로 보관합니다.
기존 프로그램을 설치했던 Windows 계정에서 실행해 주세요.

이 도구는 v2.8.3 복구 전용입니다.
